# Смета: запуск

Из `C:\Users\Administrator\Desktop\RGB_Test`:

```powershell
py run_workflow_and_report.py smeta.py
```

Создание и заполнение — аккаунт с доступом, используемый для ДДС и создания ГФР.
Согласование — Бейсембаев, утверждение — Диас. Отдельной проверки ЭЦП нет.
Настройки перенесены из текущих автотестов. Окно «Новые новости» закрывается автоматически.

Результаты передаются общему обработчику `run_structured_workflow()` в
`run_workflow_and_report.py`. Он записывает выполненные проверки через `sheet_reporter.py`
и вызывает общие `send_telegram_summary()`, `tg_send()`, `tg_photo()`.
Отдельной отправки Telegram в smeta.py нет. Используется общий `TG_ENABLED`.
Пропущенные этапы не отмечаются успешными, а перечисляются в общей сводке.

Чек-лист: 21 проверка, строки 269–289. Варианты сценариев и ограничения описаны
на вкладке «Список тестов» и в примечаниях. Дублирование перебирает до 40 смет;
создание через Excel используется только если дублирование не удалось.
Таким образом, оба способа создания не обязательно выполняются за один прогон.
Добавлены шесть отрицательных проверок в обычный запуск: пустая форма, отсутствие
названия/проекта, неподдерживаемый файл, Excel без заголовков, пустая строка сметы.
Для форм требуется недоступная кнопка либо подтверждённая валидация; для файлов —
явная ошибка импорта. Открытая форма без реакции не считается успешным отказом.
Форма закрывается после каждого случая. Если форма неожиданно закрылась при
сохранении или изменились данные, прогон прекращается; удаление не выполняется.
Проверки отсутствия названия/проекта проверяют блокировку при заданном состоянии
формы; другие обязательные данные могут также оставаться незаполненными.

Скриншоты сохраняются в `screens`; логи и JSON-результаты — в `logs`.
Коды завершения: 0 — полный успех; 1 — неуспешные или пропущенные проверки;
2 — ранний сбой или ошибка отчётности. Прогон на портале не выполнялся.

Сценарий заканчивается утверждением. Селекторы дерева видов работ и формы
утверждающего ещё требуют подтверждения на портале.
