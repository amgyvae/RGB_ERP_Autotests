# Финансы: запуск и отчётность

Запуск из `C:\Users\Administrator\Desktop\RGB_Test`:

```powershell
py run_workflow_and_report.py finance.py
```

Можно также выполнить `py finance.py`: файл передаст запуск общему обработчику.
Не используйте отдельно старую копию из Downloads: рабочий комплект находится в RGB_Test.

Рядом нужны `finance_checks.json`, `sheet_reporter.py`, `service_account.json` и общий обработчик.
Настройки перенесены из gpr_test.py: Бейсембаев — создание и согласование,
Диас — утверждение. Отдельного этапа подписания ЭЦП в ГФР нет. Пароли в консоль подготовки не выводятся.

Ожидания загрузки карточки, входа, открытия формы и перехода к графику выполняются
по готовности интерфейса. Таймауты сохранены. Убрана трёхсекундная задержка каждого
не найденного запасного селектора. Ожидания сохранения, импорта, загрузки файлов
и действий в NCALayer сохранены. Фактическое ускорение нужно замерить на портале.

## Google Sheets

27 названий совпадают с разделом «Финансы» на вкладке «Чек-лист», строки 240–266.
Выполненные проверки передаются общему `sheet_reporter.report_results()` одной пачкой.
Он записывает «Успешно (Автотест)» / «Не успешно (Автотест)» в колонку даты.
Не выполненные этапы не записываются и перечисляются в Telegram отдельно.
Предыдущие результаты за эту дату в пропущенных строках не очищаются.
При перемещении раздела нужно актуализировать диапазон в `run_finance()`.

## Telegram

Используются общие `send_telegram_summary()`, `tg_send()` и `tg_photo()`
из `run_workflow_and_report.py`, а также общие настройки `TG_ENABLED`, `TG_API`, `TG_CHATS`.
Отдельного обработчика отправки, отдельного формата и переключателя для Финансов нет.
`TG_ENABLED=True` включает отправку для всех модулей; `False` отключает её.

- Полные 27 успешных результатов: одно короткое сообщение «Автотест: Финансы — УСПЕШНО».
- Ошибки: только неуспешные проверки и причины, плюс список не выполненных этапов, если есть.
- При ошибке теста: последний скриншот ошибки именно текущего запуска, если его удалось снять.
- Ранний сбой и ошибка записи в Google Sheets: отдельная причина в сводке, без ложного полного успеха.
- Длинная сводка делится на сообщения; HTML экранируется.

Подробные результаты, анализ ДДС и URL созданного графика остаются в локальном JSON и логах:
`finance_results_<run_id>.json`, `finance_console_<run_id>.txt`, `finance_log_*.txt`.
Коды завершения: 0 — все 27 проверок успешны; 1 — ошибки проверок / неполный прогон;
2 — ошибка выполнения или доставки отчёта. При отключённом Telegram доставка не выполняется намеренно.

Обновление отчётности не усиливает бизнес-проверки: например, закрытие формы по-прежнему может
считаться успехом добавления строки. Ограничения отмечены в чек-листе.

Локальные тесты используют подмены: не запускают Chrome, не пишут в Google Sheets и не отправляют Telegram.
