Запуск тестов с записью в существующий чек-лист

1. Передавайте всю папку RGB_Test, сохраняя структуру core, config и tests.
2. Все тесты: двойной клик START_ALL_TESTS.bat.
3. Только акты: двойной клик START_ACTS.bat.
4. Из терминала, находясь в корне RGB_Test: py run_all.py acts
5. Для другого модуля: py run_all.py contacts (или другое имя из py run_all.py --list).

Не запускайте отдельные файлы tests/... напрямую: для большинства модулей такой запуск НЕ вызывает автозапись.
Не закрывайте окно до завершения. При ошибке передайте текст окна и свежий файл из logs.
На другом компьютере нужны Python, зависимости из requirements.txt, Chrome, доступ к порталу и Google Sheets. Для электронной подписи дополнительно Windows, NCALayer и настроенные пути к сертификатам.
Файл service_account.json или настройка GOOGLE_SERVICE_ACCOUNT_JSON должны быть доступны. Не публикуйте ключи, .env и сертификаты в открытом доступе.
Запись проверяется обработчиком по существующим строкам чек-листа. Новая таблица не создаётся.
